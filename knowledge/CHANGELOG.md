# Coaching knowledge changelog

## Principles: section 11 removed (24 Oct 2026, by the team)
- Removed "11. Lessons learned from feedback" from `coaching_principles.md` (it was empty: version 1, no lessons).
- New rule: players are learners, not judges. Ratings and other player actions never change the coaching knowledge. Knowledge changes only through KnowledgeScout research approved by the coach; the geometry computed in code decides what is correct.
- Player actions are used only for each player's weak spots and next drills (kept in the player's browser). "Did you understand?" flags go to a review list for the coach.

## Reference: section J removed (25 Oct 2026, by the team)
- Removed "J. Match outcome evidence" from `football_reference.md` (it was empty). The real-match learning feature is not part of the hackathon submission, which uses synthetic data only.
